Syntax

Man kan bruge var eller let til at lave dem. var brugte man i gamle dage og let er den moderne måde. Når du tildeler let en værdi, så kalder du det literals (let = 5;). Der er flere forskellige literals fx numbers og strings. Hvis det er tekst, skal der sættes doble kolon eller single kolon udenom. Arithmetic operators bruges til at regne noget ud (+,-,*). Assignment operators er noget som tildeler en værdi (=). En expression er en kombination af variabler og operators som udgører en værdi. Et JS navn skal starte med et bogstav, et dollartegn eller underscore.

https://www.w3schools.com/js/js_syntax.asp

Statements

Statements er en liste af instruktioner, som computeren udføre. Semikolon seperere statements, så de kan også laves på én linje, men i ret praksis, så har de hver sin linje.

let x, y, z; //statements 1

x = 5; //statements 2

y = 6; //statements 3

z = x + y; //statements 4

For at det er mest læsbart, så skal man helst undgå linjer, som er længere end 80 karaktere. Hvis den er længere end en linje, så skal den "knækkes" ved "="

https://www.w3schools.com/js/js_statements.asp

Comments

Kommentarer skal bruges til at forklare koden og gøre det mere læsbart, men det kan også bruges til at noget af koden ikke bliver udført. For at kommentere skal du bruge //

Ved flere linjer skal du bruge /* og */

Variabler

Variabler er containers for data, og når man laver en variabel så kaldes det "declaring a variable". Du kan erklære en variable med enten let eller const

let carName;

For at giv en værdi til variablen, så skal du bruge "=" tegnet, som også kaldes assignment operator.

carName = "Tesla";

Hvis værdien aldrig skal ændres, så skal man bruge const.

Én statement, mange variabler

Man kan starter en statement med const eller var og seperere variablerne med kolon.

let person = "Maja Andersen", carName = "Tesla", price = 200;

Arithmetic

Du kan også tilføje strings ved brug af + og =

let x = "Maja" + " " + "Thorsøe";

=

Maja Thorsøe

Hvis man sætter et nummer mellem kolontegn, så bliver resten af tallene også betegnet som strings.

let x = "5" + 3 + 7

=

537

Operators

Assignment Operator = tildeler en værdi

Addition Operator + tilføjer en værdi

Multiplication Operator * lægger værdier sammen

Comparison Operator > sammenligner værdier

man kan bruge += til at tilføje en værdi til en variabel.

let text1 = "Jeg er sød";

text1 += "og smuk."

=

Jeg er sød og smuk.
